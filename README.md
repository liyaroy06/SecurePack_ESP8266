SECUREPACK – Smart Anti-Theft Bag Security System

About the Project

Have you ever worried about someone opening your bag or stealing your belongings when you're not around?

That's the idea behind SECUREPACK!

SECUREPACK is a smart anti-theft bag security system developed using IoT technology. It is designed to detect suspicious movements and unauthorized opening of a bag. When something unusual happens, the system activates a buzzer and sends alerts to a website through Wi-Fi.

Our goal is to make everyday bags smarter and provide an additional layer of security for personal belongings.

How Does It Work?

- The MPU6050 sensor detects unusual movements of the bag.
- The Magnetic Reed Switch monitors whether the bag's zipper is opened.
- The ESP8266 processes the sensor data and handles Wi-Fi communication.
- A buzzer produces an alert when suspicious activity is detected.
- A website dashboard allows users to monitor the system status and view security events.

Technologies and Components

- MPU6050 Motion Sensor

- Zipper status
